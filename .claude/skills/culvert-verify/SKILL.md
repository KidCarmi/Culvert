# Verify a Culvert change

Read `docs/agent-context/workflows/verification.md` from the repository root before selecting or running checks. Follow that canonical procedure and read only the additional contracts relevant to the change. Report the exact scope, commands, results, and gaps; a focused pass is not aggregate CI approval.

This skill does not grant permission to expand the task, change settings, push, deploy, merge, or publish.
