## D1.2-flag findings

These are not test failures. They are pinned current behaviors that warrant a deliberate decision in D1.1h or a separate follow-up.

### Flag 1 — `ui_users.json` missing-file is silent

`(*Config).LoadUIUsersFile` returns `nil` when the file does not exist (`store.go:1296`). At higher levels of `main.go` startup this combines with default-admin bootstrap logic to silently regenerate an admin account. The D1.0 audit flagged this as HIGH risk because it can mask attacker deletion of the file.

**Pinned by:** `TestColdStart_UIUsers_MissingFile` (with explanatory comment block).
**Decision belongs in:** D1.1h or a dedicated RBAC-hardening slice. Behavior change is operator-facing (parity with the D1.1f cluster CA fail-closed change) and should not ride a test PR.

### Flag 2 — `ca.bundle` plain-PEM loads even when passphrase is set

`LoadCA` at `ca.go:189` treats any file without the `caMagic` header as plain PEM regardless of whether a passphrase is provided. A bundle written by a previous instance without encryption will load cleanly after the operator adds a passphrase. This is intentional flexibility per the source comment but it means "passphrase set + corrupted file without magic" produces a PEM-decode error rather than a decrypt error — surprising-but-safe.

**Pinned by:** `TestColdStart_CABundle_PlainPEMLoadsEvenWithPassphraseSet`.
**Decision belongs in:** future hardening if we want passphrase-set deployments to refuse plain-PEM files. Not a clear HIGH risk; documenting for visibility.

## Subtle but expected behaviors

These passed but are worth noting because they may surprise future readers:

- **`ui_users.json` containing `{}`** fails to load: envelope unmarshal succeeds with `Users == nil`, then bare-array fallback fails because `{}` is not an array. Net: error returned. Pinned in `TestColdStart_UIUsers_EmptyJSONObject`.
- **`cluster.json` containing `{}`** loads cleanly to an empty state: post-unmarshal nil-checks initialize the embedded maps. Pinned in `TestColdStart_ClusterStore_EmptyJSONObject`.
- **`ui_users.json` containing `[]`** loads cleanly via the legacy bare-array path with zero users. Pinned in `TestColdStart_UIUsers_EmptyJSONArray`.
