## Reading
- Before this change 'culvert-os-update os' could never move a kernel ABI bump: plain upgrade keeps it back.
- 'upgrade --with-new-pkgs' installs the new linux-image ALONGSIDE the running one, keeps every hold,
  and the following autoremove removes nothing (the running/previous kernel stays bootable).
- The daily security path moves the kernel only when the ABI bump is published to noble-security;
  at this snapshot 6.8.0-146 was in noble-updates only, so it correctly installed openssl/libssl3t64 and left the kernel.
